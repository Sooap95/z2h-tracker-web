# z2h-tracker-web

Front de saisie de [z2h-tracker] — un seul fichier `index.html`, servi par
GitHub Pages. **Aucune donnée ici** : les séances, poids et mensurations
vivent dans le repo privé `z2h-tracker`, lus/écrits via l'API GitHub avec
un token fine-grained saisi dans l'app (stocké en localStorage du
navigateur, jamais committé).

Copie de déploiement : la version de référence est `web/index.html` du
repo privé — modifier là-bas, puis recopier ici.
